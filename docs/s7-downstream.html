MapleSure Insurance · S7 · downstream

Downstream — build until "done"
is provably met.

The execution half: agents build, tests prove, a human approves the release. Everything here consumes the contract signed upstream — and nothing in this lane marks its own work correct. Target shape for Sprint 2, labelled as such.

What arrives

THE CONTRACT — pulled down by the developer
The handoff bundle: plan.json (stories → tasks, acceptance-criterion ids, owners, flags, rollback plans) + plan.md (the signed record). Validated against the contract before anything runs — a bad file is refused loudly, never guessed around.

Step 1 — route the work PLANNED

Tasks fan out
by stream, skill and repository access — an honest 40–70% articulated beats a claimed 100%.
AGENTIC → enters the lane
Small, testable, in a repo the agent can touch.
AI-ASSISTED, EXTERNAL → a ticket
Cross-application impact goes to the owning team — AI-drafted, human-delivered.
MANUAL → labelled hand-work
Never quietly counted as AI coverage.

Step 2 — the human's skills, before any code

The first command anyone runs is not "write code" — it is "explain this to me". Every skill reads the same downloaded bundle, so developer and tester work from the same signed facts.

🧑‍💻 Developer pack
/explain-story — the story in context: criteria, dependencies, impacts, rollback
/impact-map — what this touches, what depends on it
/scaffold — component skeleton
/codegen — smallest change that passes
🧪 Tester pack
/explain-criteria — each AC-id in the app's vocabulary
/test-scenarios — happy · edge · negative, from the criteria
/testgen — failing tests (the RED phase)
/test-data — synthetic fixtures only
🧭 Grounding
The target repo carries an architecture.md — components, data model, what is not part of the app. Every skill reads it. No fine-tuning; the repository carries the context.

Who does what

🤖 The agent
Failing test, code, full suite, docs, release candidate. Every step leaves a file.
🧑‍💼 The human
Signed the criteria upstream. Steers the agent in the IDE. Approves the release. Owns everything labelled MANUAL.
⚖️ The rules
Capped retries · verification by a step that did not write the code · failures reported, never hidden · no phase approves its own output.
